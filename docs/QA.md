## 双向追赶量测

最高难度、15 名 AI，隔离车流与攻击以观测速度策略：

1. AI 落后玩家 500 m，22 秒后差距约 14 m。
2. 玩家连续经历三次完整摔车，落后领先者约 850 m；随后 60 秒内，配合间歇氮气将最小差距缩至约 56 m。
3. 此极端情景中玩家当时仍是第 16 名，说明接近车群不等于强制逆转；不承诺三次失误后一定获胜。
4. 测试核对每步速度限制与里程连续性，追赶不通过瞬移实现。

这些是固定条件下的回归量测，不是所有路线、所有操作水平的平衡保证。真实比赛包含车流、相互攻击、补给与不同走线。

## 打包与限制

独立 arm64 应用，内含 PCK 与引擎。构建执行 `codesign --verify --deep --strict`。使用 ad-hoc 本地签名，未做 Developer ID 公证。

手柄映射已实现，但未以实体手柄验证。动画为原创程序关节动画，不是动作捕捉或布娃娃。全程地图上的近距离车手标记可能重叠，精确差距以排行榜为准。

测试日志：`builds/test-logs/`。视觉截图：`builds/test-screenshots/`。这两类构建产物不进入 Git。
