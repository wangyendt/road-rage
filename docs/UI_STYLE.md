# v4.3 视觉方向：FLIGHT DIVISION

主题是街机摩托竞速的发车区与维修站，不是管理后台。所有菜单通过同一套面板、按钮、色彩和反馈识别为同一款游戏。

- 配色：沥青墨蓝 `081321`、冷钢 `243b53`、信号橙 `ff9452`、氮气蓝 `7be3ff`、仪表白 `f0f4fa`、辅助灰蓝 `a1b6ce`。
- 字体：DIN Condensed 用于英文展示标题；Noto Sans SC 用于中文正文；DIN Alternate 用于公里数与价格。
- 布局：保留左侧主操作、中央摩托展示、右侧赛事/钱包情报的主菜单；赛前双列地图、商店四列车辆、列表与档案继续使用稳定布局和键鼠热区。
- 签名：以摩托整流罩和起跑格为来源的切角板、斜向速度线、橙色主操作与蓝色焦点轨。装饰不盖过道路预警和操作标签。
- 动效：按钮焦点渐亮，不移动点击区域；背景流线低强度运动。关闭动效设置时停止环境流线，反弹文字保留静态淡出。

布局简图：
```
主菜单：[品牌 / 主操作]  [实机摩托]  [赛道 / 钱包 / 车库]
赛前：  [地图卡][地图卡]            [人数 / 难度]
        [地图卡][地图卡]            [翻页]
        [短程][中程][长程]          [开始]
车库：  [车辆][车辆][车辆][车辆]    每卡显示弹性/缓冲/控向
```

避免叠加过量霓虹：蓝色用于状态、橙色用于主要动作；比赛 HUD 不覆盖菜单的背景流线。真实 UI 截图后检查文本溢出、对比度与小窗口等比缩放。
