# v4.4 · SIGNAL / PURSUIT

## 视觉层级

警示集中在中央下方 480×96 状态卡与右侧小地图，不进行全屏红闪，不遮住道路中远处。自绘警灯、手铐、对勾、奖杯、格旗和断车图形，避免平台 emoji 字体差异。

追捕进入后，小地图背景/路线保留原色并平滑混入红色（1.25 Hz 正弦，透明度 0.045–0.15），车手原色与文字保持可辨；红蓝警灯条与实体警车灯使用相同比赛时钟。追捕、倒地被捕危险、脱逃读条、脱逃成功有不同标签和图标。成功确认保留 3.5 秒，然后消失。关闭地图也保留追捕卡。

关闭“震动 / 界面动效”后，警示、警车灯和地图定位环不闪烁；结算直接呈现最终数字与静态背景。暂停/档案/设置页面不推进比赛时钟，回到比赛不跳闪。发车灯依然响应 3–2–1–GO 的必要状态变化，但不做缩放跳动。

## 发车与警笛

- 原有 3.5 秒发车流程：0.5 秒就位，3–2–1 依次点亮红色 LED，三次 840 Hz 短音；GO 时灯变绿，播放 1260 Hz 长音。合成音带短启动/释放包络与轻微延迟尾音，起止无硬切爆音。
- 警笛为两条 48 kHz 原创合成 WAV：4 秒循环、540–1420 Hz 扫频，长鸣 0.5 Hz / 急促 4 Hz；相位由频率积分生成，含二/三次谐波。循环首尾相位连续，无原循环的定期静音缝。
- 最近占优警车的 12–75 m 距离控制急促层，平滑等功率混合，避免突变。保留原有 24 m 距离衰减尺度，240–360 m 平滑淡出。
- 既有 `siren_acoustics.gd` 以 343 m/s 声速、声源和玩家沿连线方向的速度计算多普勒，音高限在 0.78–1.28。同速远近不改音高，远近另行影响音量和高频。
- 独立 Police 总线的低通随强度从约 1.35 kHz 开到 6.2 kHz；横向位置映射为平滑左右声像（上限 ±0.8）。不改变引擎、武器或音乐的声像/滤波。
- 暂停、离开赛事和结算使两条警笛平滑归零。脱逃警车保留原有 1.5 秒退场渐弱。被捕播放独立机械闭锁/无线电风格收尾音。
- 这是街机化的原创合成声学，不是某地区警车的实录，也没有做建筑反射/真实三维声场模拟。

## 实现与复现

- `scripts/race_feedback.gd`：纯展示状态与结算样式；`hud.gd`：矢量图标、发车灯、地图与结果绘制。
- `police.gd`：真实脱逃时间、声源声像和急促层参数；`audio.gd`：双层音色、专用总线。
- 生成素材：`python3 tools/generate_race_feedback_audio.py`（仅 Python 标准库）。如果重新运行旧 `generate_audio.py` / `generate_career_audio.py`，最后再运行此脚本以恢复 v4.4 的 count/go/siren 素材。
- `tests/test_race_feedback.gd`：30 项纯状态/真实游戏逻辑断言。
- `tests/test_race_feedback_ui.gd`：20 项实际 Metal 渲染、键鼠点击及原生音频节点/总线断言，并保存各状态截图。包含局部像素变化、关闭动效后小地图像素稳定、暂停不重发提示音、原生低通/声像/双层混合与三种完赛名次。
- `tools/capture_race_feedback.gd`：约 22 秒有声实机演示。为便于展示设置警车/玩家位置和结果，不是完整自然竞赛；图标、脱逃保持判定、结算收据与音效均走实际游戏代码，测试模式不读写个人存档。
