# v1.0 设计说明

## 核心体验

90 秒以内完成一场高速度、低操作门槛的摩托竞速格斗。自动油门减少持续按键负担；贴近对手、选择攻击方向、管理氮气和躲避车辆是主要决策。

## 数值

- 赛道：5400 m，3 个里程区段。
- 常规极速：74 m/s（约 266 km/h）；氮气极速：99 m/s（约 356 km/h）。
- 转向：约 10.5 m/s 横移；氮气时稍快。
- 氮气：总量 100，每秒消耗 28；未使用时每秒回复 8。
- 攻击：0.43 s 冷却；纵向 6.4 m、横向 3.5 m 的街机容错范围。
- 对手两次命中倒地，失速约 3 s，随后恢复。
- 交通车辆碰撞损伤 23、对手攻击 12、护栏擦碰 8、车手擦碰 6；连续受伤保护 1.1 s。
- 修复：25 耐久；氮气道具：35；命中/擦身也返还氮气。
- 连击有效时间：5 s，分数倍率最高按 5 倍计算。

## 打击感层次

1. 骑手手臂挥击与球棒显示。
2. 发光弧面表现攻击方向。
3. 命中实体火花与不同轻重的合成冲击音。
4. 55–100 ms 的局部慢动作（不是冻结整个 UI 或音频）。
5. 可关闭的镜头震动、短促曝光/边缘受伤染色。
6. 对手位移、降速、倾倒，以及即时连击、分数、氮气奖励。

## 渲染风格

工业设计式冷蓝装甲与珊瑚橙车漆；黄昏城市的暖天际线、冷色建筑窗光、青色氮气。
UI 使用大号窄体英文标题与简洁中文信息，不把赛道遮成仪表盘。
特效主要位于画面边缘，交通障碍与攻击预警保持清晰。

## 技术取舍

- 原创程序化几何确保资源可维护、无需下载大型素材。
- 循环赛道分段减少场景规模；共享几何和材质。
- 预合成 WAV 避免实时音频采样给 GDScript 带来负担。
- 不使用真实刚体驾驶，优先保证碰撞反馈稳定和控制可预期。
- AI 根据相对距离适度追赶，并尝试避开交通。
- 存档为 Godot user:// 下的本地 ConfigFile；无网络通信。

## 明确未实现

联网、开放世界、车辆改装商店、多赛道生涯、真实物理、专业动画与写实扫描资产。
不以菜单占位或未生效按钮冒充这些功能。
