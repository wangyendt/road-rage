## 物理规则

沿用街机 2g 重力（19.6 m/s²），采用不超过 1/120 s 的子步。坡顶是因接触约束失效自然离地，不按脚本固定加高度。

触地时取得道路法线 `n = normalize((-slope, 1))`，把前进和竖直速度组合为 `v`：

```
v_after = v_before - (1 + e) * dot(v_before, n) * n
```

只对朝向路面的入射速度执行，切向分量保留，法向速度反向并乘以 e。上坡着地的部分前进速度转为上升速度；水平冲量返回比赛积分器，避免在斜坡上凭空增加动能。禁止倒车的街机约束将负的前进速度钳到零，只额外耗能。

- 平地上每次反弹高度/法向动能约为上一次的 **e²**。弹簧侠 0.68²≈0.462，下一跳保留约 46% 高度；镇山 0.16²≈0.026。
- 回弹法向速度小于 2.2 m/s，或刚结束的是小于 0.08 m 的微小跳动时贴地，避免无限抖动。
- 道路坡度变化、重力和持续发动机推力会改变整场轨迹；跨过新的山坡后，高度不保证仍按平地几何级数下降。没有硬编码“必须弹三次”。
- 受伤按法向冲击的耗散部分和车型缓冲阈值计算。同一连弹不重复发飞跃奖励、氮气或重复追加重落地伤害；首次重着地依然有风险。
- 碰撞恢复期间不触发新的反弹，重开清空连弹计数。暂停冻结物理和提示时间线。

这是有单位、有恢复系数、可验证能量损耗的街机接触模型，不是完整刚体摩托、轮胎或悬挂弹簧动力学仿真。水平行驶和接触使用分步积分，未实现完整连续碰撞求解。

## 反馈和镜头

实际反弹触发“触底反弹 / REBOUND ×N / 蓄势上扬”，伴随上扬折线、放大淡出字样、放射短线和扩散地面冲击环；是游戏趣味彩蛋，不连接行情。落地音随连弹次数变化音高。

提示持续约 1.15 秒，连续触地更新连弹数。镜头直接跟随车手竖直参考系，再平滑偏移，高空不会把车手甩出画面；附近装饰性横跨路牌在腾空时隐藏，避免穿模遮挡。关闭“震动 / 界面动效”时，界面流线停止，文字改为静态大小淡出。

主菜单、赛前设置、车库、档案、设置、改键、指南、暂停、结算及比赛面板共用切角板与新按钮。焦点渐亮不移动热区；960×600 和 1280×800 验证过等比缩放和点击。风格方向见 `UI_STYLE.md`。
