# ROAD RAGE · 极限狂飙

一个可从菜单玩到结算、可重复挑战的 **3D 单机摩托竞速格斗游戏**。
原创程序化模型、原创合成音效和电子配乐；基于 Godot 4，针对 Apple Silicon Mac 构建。

## 立即开玩

- 双击本仓库的 **`启动游戏.command`**。
- 或双击 **`builds/Road Rage.app`**。该应用已包含运行时，无需打开 Godot，也无需联网。
- 开发时，在 Godot 中导入根目录的 `project.godot`，按 **F5** 运行整个项目。

本机项目目录：`/Users/wayne/Documents/work/code/game/road-rage`。
独立应用构建目标：macOS 13+ / Apple Silicon（arm64）。已在 macOS 26.6、M1 Max、Godot 4.7.2 上验证。

## 玩法

**港湾高架 / HARBOR RUN**：5.4 公里，玩家与 5 名 AI 车手同场竞速。
自动油门让你专注走位和战斗。靠近对手，左右出击；两次命中可将其击倒，使其暂时减速。
避开交通车辆和护栏，在车体耐久耗尽前冲过终点。

- 三段路线：临港起跑、霓虹立交、决胜桥段。
- 氮气冲刺：提高极速、改变镜头视场、喷射尾焰、屏幕速度线与轻微色散。
- 打击反馈：挥击弧光、火花、命中短暂停顿、镜头震动、分层冲击音效。
- AI 对手：追赶、横向走位、交通避让、攻击预警与反击、击倒后恢复。
- 交通碰撞、护栏擦碰、车手擦碰、极限擦身奖励。
- 青色圆环补充氮气；绿色十字修复车体。
- 连击倍率、击倒奖励、名次/耐久冲线奖励、个人最佳成绩。
- 中文界面、暂停、设置、结算、重开；切出窗口自动暂停。
- 高/低画质、音量、音乐、震动和难度设置；设置与记录保存在本机。

### 操作

| 动作 | 键盘 | 手柄映射 |
|---|---|---|
| 转向 | A / D 或 ← / → | 左摇杆 |
| 刹车 | S / ↓ | LT |
| 氮气 | 按住空格 | RT / A |
| 向左 / 向右攻击 | J / K | LB / RB |
| 自动选择攻击方向 | Shift | — |
| 暂停 / 继续 | Esc / P | Start |
| 重开（结算页） | R | 菜单选择 |
| 全屏 / 静音 | F11 / M | — |
| 菜单导航 | ↑ ↓ / Enter，也可鼠标点击 | 十字键 / A |

Mac 上 F11 可能需同时按 Fn，取决于系统功能键设置。手柄映射已实现，未用实体手柄做硬件验证。

### 上手技巧

1. 不用一直按前进键；松开刹车就会自动加速。
2. 对手上方出现 **[J] / [K]** 时已进入攻击范围。连续两击最划算。
3. 留意橙色「攻击预警」，及时拉开横向距离，或先出手打断。
4. 氮气用完后松开空格，恢复一些再冲刺。持续按住不会反复触发空氮气。
5. 近距离安全超车会返还氮气；血量低时留意绿色修复道具。
6. 想要更轻松就选「街机」；低功耗游玩可选「流畅」画质，限制为 60 FPS。

## 开发结构

```text
assets/       原创 WAV 音效、噪声纹理资源、图标、Godot 许可证
scenes/       入口场景 main.tscn
scripts/
  main.gd     状态机、竞赛、输入、碰撞、攻击、存档与测试入口
  world.gd    循环赛道、弯道、城市、桥梁、环境和交通模型
  bike.gd     摩托/骑手模型、倾斜、挥击和氮气动画
  hud.gd      自适应中文 UI、菜单和比赛 HUD
  audio.gd    音效声部、引擎循环、音乐与音量管理
  fx.gd       命中火花与挥击弧光
  geo.gd      共享材质及几何体工厂
shaders/      沥青、建筑窗户、画面后处理
tests/       实际游戏逻辑及渲染界面集成测试
tools/       音频生成、macOS 打包、引擎许可证导出
```

采用赛道里程坐标和街机碰撞模型，不依赖刚体车辆求解器。玩家保持在局部坐标原点附近，赛道循环复用，避免长赛道浮点精度问题。道路按中心线与切线放置，车辆、道具共用相同坐标变换。

默认使用 **Mobile 渲染器 + Metal**，开启 MSAA、阴影和辉光。这里的 Mobile 是 Godot 渲染管线名称，应用仍是桌面游戏。
字体通过系统字体回退取得；未复制或分发 macOS 字体文件。

## 构建独立 Mac 应用

```bash
./tools/build_macos.sh
```

生成 `builds/Road Rage.app` 和 `builds/RoadRage-macOS-AppleSilicon.zip`。
需要已安装 Godot 和 Xcode 命令行工具；可通过 `GODOT_BIN` 指定其他 Godot 可执行文件。

本构建将本机 Godot 的 arm64 引擎与导出的 PCK 一起打包，因此无需另行下载导出模板。
使用了编辑器构建作为运行时，体积比官方 release export template 大；游戏仍以独立游戏模式启动。
应用进行了本地 ad-hoc 签名，没有 Apple Developer ID 公证。正式公开分发前应使用发行证书签名与公证。

## 音频再生成

```bash
python3 tools/generate_audio.py
```

再生成工具依赖 NumPy。**玩游戏和打开 Godot 项目不需要 Python 或 NumPy**，WAV 已包含在仓库中。
合成内容包括摩托引擎、挥击、碰撞、氮气、补给、倒计时、结算，以及 132 BPM 原创电子配乐。
