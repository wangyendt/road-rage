# ROAD RAGE · 极限狂飙 v4.9.0

可从菜单玩到结算的 **3D 单机摩托竞速格斗游戏**。原创程序化模型、合成音效和电子配乐；Godot 4，面向 Apple Silicon Mac。

## 立即开玩

- 双击 `启动游戏.command`，或 `builds/Road Rage.app`；独立应用内含运行时，无需联网或打开 Godot。
- 开发时导入 `project.godot`，按 F5。
- 本机目录：`/Users/wayne/Documents/work/code/game/road-rage`。
- 构建目标 macOS 13+ / arm64；验证机器为 M1 Max、macOS 26.6、Godot 4.7.2。

开始游戏后先选择场景、短/中/长赛程、1–15 名 AI 和 1–5 级难度，再开始竞赛。

- 两项规则保存并于 **下一场** 生效，不会在当前比赛突然改路；旧存档维持空气墙开、对向车道关。维修仍免费，原被捕罚款不变。详见 `docs/ROAD_RULES.md`。

## v4.5 无伤落地与空中特技

- 所有地图、所有摩托的自然腾空和连续反弹落地均不扣耐久、不强制翻车或进入找车流程；保留悬挂、触底反弹、冲击音和飞跃奖励。无需做特技也享受无伤落地。
- 大腾空时按 **E**（手柄 X）做“超人展体”：车手离座伸展、自动回座；靠近前方路面会提前收动作。需要离地至少 6 m 且预计剩余腾空至少 1 s，落地后另奖 300 分 / 12 氮气。
- 同一次起飞及后续连弹只计一次特技，动作中暂不攻击/切武器。撞车、武器攻击及警车碰撞仍有伤害，会中断特技；这不是无敌模式。
- 设置内可改特技键；帮助、腾空 HUD 和结算显示相应状态。后视镜排除自己的车手模型，避免离座时挡住视野。规则与验证见 `docs/STUNTS.md`。

## v3.2 脱逃、动态警笛与结算动效

- 警车采用 6 秒拦截加速 / 10 秒散热节奏，散热时可以利用氮气甩开；警车也会被交通车辆阻挡。
- 进入近距离追逐后，领先警车 100 m 并保持 2.5 s 即可脱逃；尚未接近的警车需拉开 230 m。HUD 显示当前阈值与倒计时。
- 成功脱逃加 300 分，警车关闭警灯、减速驶离，不瞬移。至少 18 s 且继续行进 1100 m 后才可能出现下一轮追捕。
- 警笛振幅按距离衰减，音高按声源/玩家沿连线方向的相对运动产生多普勒变化：接近偏高、远离偏低，同速时不因距离远近改变音高。音量和音高变化均平滑过渡。
- 结算面板滑入淡入，分数、奖金和罚款逐步计数；胜利有彩屑与扩散光环，失败有斜向扫光，被捕带红蓝氛围。按钮始终可点击，动画不重复发钱。

- 全程路线小地图显示所有车手；真实 3D 后视镜显示身后的道路与追兵。
- 5 级难度调整反应、预判、操控、进攻、氮气和速度；最高级主动避让攻击、抓失误、末段冲刺。
- 双向非线性追赶：落后 AI 加速、领先 AI 适度收速，落后玩家获得有限引擎及氮气恢复帮助；不瞬移、不锁死名次，也不保送胜利。
- 玩家和 AI 均有完整恢复动画：撞飞、翻滚落地、起身、跑回摩托、扶车上车。恢复期间比赛继续。
- 12 项键盘动作支持改键、冲突交换、恢复默认和自动保存；HUD 提示同步变化。

保留氮气尾焰、速度线、挥击弧光、火花、命中停顿、震动、分层冲击音；交通碰撞、极限擦身、补给、连击、计分、结算和重开。

改键入口：主菜单或暂停 → 游戏设置 → 快捷键设置。支持单键；方向键、Esc、Enter、F11、M、R 为保留键。手柄暂为固定映射，未用实体手柄验证。Mac 上 F11 可能需要同时按 Fn。

自动油门，无需持续按前进键。靠近对手左右出击，拳脚连续两次命中可击倒，重型武器可一击击倒完整耐久 AI。橙色攻击预警出现时拉开距离或先出手打断。绿色十字修复车体，青色圆环补充氮气；氮气耗尽后需松开按键重新蓄力。

警笛、观众欢呼和失败音效再生成：`python3 tools/generate_career_audio.py`，仅用 Python 标准库。

风声与落地音再生成：`python3 tools/generate_terrain_audio.py`，仅用 Python 标准库。

受击闷哼与鞭声再生成：`python3 tools/generate_combat_audio.py`，仅用 Python 标准库。
