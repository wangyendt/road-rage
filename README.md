# ROAD RAGE · 极限狂飙 v4.1

可从菜单玩到结算的 **3D 单机摩托竞速格斗游戏**。原创程序化模型、合成音效和电子配乐；Godot 4，面向 Apple Silicon Mac。

## 立即开玩

- 双击 `启动游戏.command`，或 `builds/Road Rage.app`；独立应用内含运行时，无需联网或打开 Godot。
- 开发时导入 `project.godot`，按 F5。
- 本机目录：`/Users/wayne/Documents/work/code/game/road-rage`。
- 构建目标 macOS 13+ / arm64；验证机器为 M1 Max、macOS 26.6、Godot 4.7.2。

开始游戏后先选择场景、1–15 名 AI 和 1–5 级难度，再开始竞赛。

## v4.1 武器与夺取

- 15 名 AI 分别配备刀、长枪、剑、戟、斧、钺、钩、叉、双节棍、皮鞭、铁链、狼牙棒、战锤、短棍、三节棍；头像列表和档案显示武器。
- 玩家每局从拳击开始，按 **Q** 在拳击、踢击和已夺武器之间循环；J / K 向左 / 右攻击，Shift 自动选边。Q 支持改键，也可点击右上角武器卡。
- 亲自近战击倒持械 AI 后自动夺取并装备其武器；对方重新上车后只剩拳脚。重复击倒同一空手车手不会复制武器，交通事故或 AI 互殴不赠送战利品。
- 玩家摔车保留本局战利品，新比赛重置；攻击收招期间禁止切换，避免取消重武器冷却。
- 武器的距离、伤害、冷却、硬直和击退不同：钩可拉近敌人，皮鞭远距压制，双节棍快连，战锤强击退但收招慢。
- 实体程序化武器模型、左右持握、踢腿、柔性链节展开、命中倾斜与夺取光轨；受击车手播放分音色的原创合成闷哼，随距离衰减。空挥或无敌保护不播放受伤声音。
- 规则、武器表和技术边界见 `docs/WEAPONS.md`。

- **8 台摩托 / 8 张地图 / 9 类交通车辆**：新车与新地图在车库、选图界面的第二页，使用“更多摩托 / 更多地图”翻页。
- 新地图：海崖天际线、风车丘陵、矿场运输线、雨雾山脊；海岸、风机、施工锥桶/吊架、雨雾与湿亮路面形成不同氛围。
- 新车：NOMAD 拉力、COMET 电光、MAMMOTH 远征、FALCON 隼影，外观、性能、抓地和落地缓冲各有差别，旧存档及已购车辆保留。
- 连续起伏道路与坡顶自然起飞：速度、坡度和重力决定飞行，慢速能稳稳过坡；玩家和 AI 都遵循接地/腾空逻辑。
- 悬挂压缩回弹、空中风声、落地冲击、飞跃分数；HUD 显示离地高度/腾空秒数，结算记录飞跃次数和最远距离。

- 施工路段实际收窄；碎石和湿滑路况降低抓地与制动。详细参数与技术边界见 `docs/TERRAIN.md`。
- 中文字体随包携带，离线完整显示新车型及地形信息。

## v3.2 脱逃、动态警笛与结算动效

- 警车采用 6 秒拦截加速 / 10 秒散热节奏，散热时可以利用氮气甩开；警车也会被交通车辆阻挡。
- 进入近距离追逐后，领先警车 100 m 并保持 2.5 s 即可脱逃；尚未接近的警车需拉开 230 m。HUD 显示当前阈值与倒计时。
- 成功脱逃加 300 分，警车关闭警灯、减速驶离，不瞬移。至少 18 s 且继续行进 1100 m 后才可能出现下一轮追捕。
- 警笛振幅按距离衰减，音高按声源/玩家沿连线方向的相对运动产生多普勒变化：接近偏高、远离偏低，同速时不因距离远近改变音高。音量和音高变化均平滑过渡。
- 结算面板滑入淡入，分数、奖金和罚款逐步计数；胜利有彩屑与扩散光环，失败有斜向扫光，被捕带红蓝氛围。按钮始终可点击，动画不重复发钱。

## v3.1 公里数与全员数轴

- 顶部显示已行驶公里数、距离终点公里数、全程长度及完成百分比，公里数保留三位小数（米级显示精度）。
- 左侧所有车手共用同一公里刻度，每人独立一行：名次、头像、姓名、相对玩家差距、实际进度标记和剩余公里数。橙色菱形突出玩家。
- 16 人同时起跑也不会合并或遮挡标记；倒地显示交叉标记，冲线显示终点圆环和“到达”。
- 点击 AI 行查看精确的已行驶/剩余公里数、百分比和相对距离。资料页暂停比赛，数轴同步冻结。
- 四条路线均使用自身实际长度；到达后固定 100%，不会出现负的剩余里程。

## v3 新功能

- 四条路线终点均有实体黑白格终点线、48 名挥手跳跃的观众、旗帜、看台和欢迎牌，接近时可听到欢呼。
- 警车带交替红蓝警灯与警笛，会追赶和碰撞车手；警员会下车接近倒地车手。人在空中或已经重新骑车时不会被抓。
- 地面恢复期间被抓会罚款并退出本场，无比赛奖金；余额不足的部分记为待缴罚款，由未来奖金优先抵扣。
- 独立于分数的持久钱包，初始 $1000。冲线奖金按名次、难度和 AI 数量计算，结算显示奖金、抵扣与实际入账。
- 4 台可换摩托：免费 RR-09、$2400 LYNX、$5600 TITAN、$9800 SPECTRE。车色、车身部件、极速、加速、操控和防护均实际生效。
- 已有车辆免费换乘；不足额或有待缴罚款时不会误扣钱购买。钱包、欠款、拥有的车型和选择自动保存。

入口：主菜单或赛后结算 → **车库 / 摩托商店**。比赛中不开放换车。规则和价格见 `docs/CAREER.md`。

## 场景与竞赛

| 场景 | 长度 | 风格 |
|---|---|---|
| 港湾高架 | 5.4 km | 落日海湾、城市、跨海桥梁 |
| 赤岩峡谷 | 4.8 km | 砂岩山脊、仙人掌、连续弯道 |
| 雪岭林道 | 5.2 km | 针叶林、雪峰、冷色山地 |
| 霓虹都市 | 6.2 km | 夜间都市、灯光隧廊、密集车流 |
| 海崖天际线 | 6.8 km | 海岸灯塔、长坡与飞跃 |
| 风车丘陵 | 7.2 km | 风机群、连续波浪坡 |
| 矿场运输线 | 5.8 km | 重卡运输、施工窄口、碎石路 |
| 雨雾山脊 | 6.6 km | 湿滑山路、雨雾、长坡急弯 |

- 最多 16 人同场：玩家加 15 名原创 AI，具有头像、姓名、年龄、城市、座驾、风格和不同驾驶属性。
- 点击实时排行榜中的车手，或按 Tab 查看档案；资料页暂停比赛。
- 全程路线小地图显示所有车手；真实 3D 后视镜显示身后的道路与追兵。
- 5 级难度调整反应、预判、操控、进攻、氮气和速度；最高级主动避让攻击、抓失误、末段冲刺。
- 双向非线性追赶：落后 AI 加速、领先 AI 适度收速，落后玩家获得有限引擎及氮气恢复帮助；不瞬移、不锁死名次，也不保送胜利。
- 玩家和 AI 均有完整恢复动画：撞飞、翻滚落地、起身、跑回摩托、扶车上车。恢复期间比赛继续。
- 12 项键盘动作支持改键、冲突交换、恢复默认和自动保存；HUD 提示同步变化。

保留氮气尾焰、速度线、挥击弧光、火花、命中停顿、震动、分层冲击音；交通碰撞、极限擦身、补给、连击、计分、结算和重开。

## 操作

| 动作 | 默认键盘 | 手柄映射 |
|---|---|---|
| 转向 | A / D 或左右方向键 | 左摇杆 |
| 刹车 | S / 下方向键 | LT |
| 氮气 | 按住空格 | RT / A |
| 左 / 右攻击 | J / K | LB / RB |
| 自动选边攻击 | Shift | — |
| 切换拳脚 / 武器 | Q | Y |
| 暂停 / 继续 | Esc / P | Start |
| 车手信息 | Tab | Back |
| 小地图 / 后视镜 | V / B | — |
| 重开（结算） | R | 菜单选择 |
| 全屏 / 静音 | F11 / M | — |
| 菜单 | 鼠标或方向键 + Enter | 十字键 / A |

改键入口：主菜单或暂停 → 游戏设置 → 快捷键设置。支持单键；方向键、Esc、Enter、F11、M、R 为保留键。手柄暂为固定映射，未用实体手柄验证。Mac 上 F11 可能需要同时按 Fn。

自动油门，无需持续按前进键。靠近对手左右出击，拳脚连续两次命中可击倒，重型武器可一击击倒完整耐久 AI。橙色攻击预警出现时拉开距离或先出手打断。绿色十字修复车体，青色圆环补充氮气；氮气耗尽后需松开按键重新蓄力。

```bash

# 满员最高难度自动驾驶，仅供回归验证，不写入个人成绩：
/Applications/Godot.app/Contents/MacOS/Godot --path . -- \
  --autoplay --ai=15 --level=5 --course=3 --quit-after=110
```

测试脚本覆盖 319 项逻辑和真实渲染输入断言。详情见 `docs/QA.md`；策略说明见 `docs/DESIGN.md`。`--course=0..7` 对应上表顺序。

构建需要已安装 Godot 与 Xcode 命令行工具，可用 `GODOT_BIN` 指定引擎。输出 `builds/Road Rage.app` 和 `builds/RoadRage-macOS-AppleSilicon.zip`。

构建将本机 Godot arm64 引擎与 PCK 打包，免下载导出模板。编辑器运行时比正式 release template 大，游戏仍以独立游戏模式启动。使用 ad-hoc 本地签名，未进行 Apple Developer ID 公证。

音频再生成：`python3 tools/generate_audio.py`，仅再生成需要 NumPy；游玩无需 Python。含引擎、挥击、碰撞、氮气、补给、倒计时、结算和 132 BPM 原创电子配乐。

警笛、观众欢呼和失败音效再生成：`python3 tools/generate_career_audio.py`，仅用 Python 标准库。

风声与落地音再生成：`python3 tools/generate_terrain_audio.py`，仅用 Python 标准库。

受击闷哼与鞭声再生成：`python3 tools/generate_combat_audio.py`，仅用 Python 标准库。

## 范围

原创风格化街机实现，并非原版资产逐项复制。包含八台可选摩托、八种场景和十五名 AI；提供自定义街机接地/重力求解，而非完整刚体驾驶模拟。尚无联网多人、开放世界或锦标赛赛程。
